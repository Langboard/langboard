# Contributing to Langboard

Thanks for your interest in contributing! We welcome pull requests, issues, and feedback.

## Before You Start

- Make sure there's no open issue or PR that already addresses your change.
- If your change is significant, open an issue first to discuss your idea.
- Be respectful and follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## How to Contribute

1. Fork the [Langboard GitHub repository](https://github.com/yamonco/langboard)
2. Create a new branch following [GitHub flow](https://docs.github.com/en/get-started/using-github/github-flow)
   - fix/...
   - feat/...
   - ...
3. Submit a pull request to the `main` branch with a clear title and description. Reference any issues fixed, for example `Fixes #1234`. Ensure your PR title follows the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) format.
4. A maintainer will review your PR and may request changes.

## GitHub Collaboration Language

Write PR titles, descriptions, reviews, and comments in English, including text
generated by bots and automation. Product translations, user input examples, and
quoted external data may retain their original language. Keep localized literals
in inline code, fenced code blocks, or Markdown block quotes. For longer examples,
wrap only the example in these paired markers:

```text
<!-- langboard:localized-example:start -->
Localized example content
<!-- langboard:localized-example:end -->
```

Keep explanatory prose outside the markers in English. PR titles have no Markdown
exemptions. The collaboration-language check rejects Korean prose and unclosed,
nested, or unmatched example markers. Langboard board content is outside this
GitHub collaboration policy.

The workflow reads event payloads as data and checks out the repository's default
branch with read-only permissions; it never checks out or executes PR code. Its
script and tests must exist on the default branch before event enforcement can
operate. Run its regression suite locally with:

```sh
python -m unittest discover -s .github/scripts -p test_collaboration_language.py -v
```

## Pull Request Checklist

- Run `make format`
- Run `make lint`
- Run `make unit_tests`
- Update relevant documentation when behavior or configuration changes

Thank you for helping improve Langboard!
